## PromptForge Studio — How to Use This Kit

### ⚡ Quick Start
1. Open ChatGPT / Claude / Gemini (or run Ollama locally).
2. Copy the entire prompt from any `.txt` file below.
3. Replace the `[placeholder]` with your details.
4. Run it → get the output.

### 🧪 Test each prompt (free):
- Sales Page: paste into ChatGPT → “write a landing page for AI CRM”
- Cold Email: paste → “write 3 emails for a Shopify app”
- React Component: paste into your IDE → get full .tsx code

### 🛠️ Tip: Combine prompts
Example: Use Prompt 01 (sales page) → use the copy in Prompt 03 (ad variants).
